# Password Strength Checker

An educational tool for reviewing basic password characteristics.

## Features

- Length checks
- Character checks
- Local processing

## How to Use

Enter a sample password to review its characteristics.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Test a short sample password.
- [ ] Test a long sample with varied characters.
- [ ] Verify that password input is not saved or transmitted.
